# Endpoints deferred to findata-ext (genuinely not declarative)

- `/ratios/:symbol` (fundamentals+analysis): pivot_raw jsonb reshape: moves raw jsonb into named 'ratios' map, drops 7 META_KEYS, per-leaf coerce_float — not expressible as SELECT cols.
- `/financial-growth/:symbol` (fundamentals+analysis): pivot_raw jsonb reshape into 'growth' map (fundamentals.financial_growth.raw) with META_KEYS drop + float coercion.
- `/income-statement-growth/:symbol` (fundamentals+analysis): pivot_raw jsonb reshape into 'growth' map (fundamentals.income_statement_growth.raw) with META_KEYS drop + float coercion.
- `/balance-sheet-growth/:symbol` (fundamentals+analysis): pivot_raw jsonb reshape into 'growth' map (fundamentals.balance_sheet_growth.raw) with META_KEYS drop + float coercion.
- `/cash-flow-growth/:symbol` (fundamentals+analysis): pivot_raw jsonb reshape into 'growth' map (fundamentals.cash_flow_growth.raw) with META_KEYS drop + float coercion.
- `/analyst-estimates/:symbol` (estimates+investors): jsonb/long->wide pivot: rows are pivoted into a per-period 'metrics' map keyed by metric name with per-leaf float coercion (low/high/avg/num_analysts), preserving first-seen period order via a ranked_periods CTE — not expressible as a single declarative rows/envelope SQL shape.
- `/etf/:symbol/holdings` (corpactions+valuation+etf+earnings): Multi-query orchestration: pre-query max(as_of) when asof absent, then a second query, wrapped in a custom jsonb envelope {etf_symbol, as_of, count, holdings} with as_of derived from the pre-query result (not a simple count+data envelope).
- `/peers/:symbol` (reference+macro+events): Handler returns a flat JSON array of peer_symbol strings (e.g. ["1337.HK","AAPL","DELL"]), not row objects. The query maps each row to Value::String. Not expressible as shape=rows/one/envelope which all emit objects; needs ext to collapse the single column to a bare string array.
- `/exchange-market-hours` (reference+macro+events): Handler computes an is_open boolean per row in Rust (parse_hour + compute_is_open: parses '9:30 AM -04:00' into time+tz, gets current time in that tz, weekday/range check) and injects it as a top-level field. Cannot be expressed as a static SQL column; requires per-row code-side computation in ext.
- `/prediction-markets/markets/search` (predictionmarkets+kols): Dynamic UNION ALL: polymarket and/or kalshi branches conditionally assembled by venue param, each with status-dependent WHERE clauses and per-branch positional binds — cannot be expressed from a fixed allow-list fragment set.
- `/prediction-markets/candles/:venue/:market_id` (predictionmarkets+kols): Heavy venue+interval-dependent SQL dispatch: polymarket 1m/5m merges live cagg with orderbook-midprice cagg via jsonb_array_elements_text subquery on clob_token_ids; 15m/60m/1440m merges with archive table; DISTINCT ON priority UNION; kalshi takes a plain path. Cannot reduce to one allow-list-driven SQL template.
- `/kols/tweets` (predictionmarkets+kols): Redis live read: fans out per-roster-handle LRANGE on kol_tweets:by_handle:* lists, merges, sorts by created_at, then pydantic-style projects to KOLTweet shape — not a SQL query.
- `/kols/tweets/by-symbol/:symbol` (predictionmarkets+kols): Redis live read: LRANGE on kol_tweets:by_symbol:<SYMBOL> then KOLTweet projection — not a SQL query.
- `/kols/:handle/tweets` (predictionmarkets+kols): Redis live read: LRANGE on kol_tweets:by_handle:<handle> then KOLTweet projection — not a SQL query.
